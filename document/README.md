# Document folder

The `pe-doc` folder for the briefing: [`proposal.md`](proposal.md) (generated from [`../template.md`](../template.md) by `scripts/build.sh`; don't edit it here), [`extra.css`](extra.css) for the cards, and [`figures.json`](figures.json), which traces every printed figure to its source.

Build from the repo root with `scripts/build.sh`. The PDF, HTML and DOCX it writes here are not committed.
